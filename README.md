# plasticAquarium

プラスチックゴミの量を計測するiOSゲームアプリ

## Features
- 捨てるプラスチックゴミの量を入力することで、その量に応じた魚をゲーム内で入手できる
- 獲得した魚がゲーム内の水槽を泳ぐ
- ゴミを捨てるときはカメラ認証を行う

## Environment
- VSCode（コーディング）
- Xcode（実行テスト）
- Swift
- SwiftUI
- コーディング生成AI（Codex）活用
